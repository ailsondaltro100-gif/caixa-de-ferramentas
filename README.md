# 🧰 Caixa de Ferramentas

A toolbox web application with useful utilities.

## Features

- Simple and clean interface
- Multiple tool cards for different utilities
- Integrated with Vercel Speed Insights for performance monitoring

## Tech Stack

- Pure HTML/CSS/JavaScript
- Vercel Speed Insights for performance tracking

## Setup

1. Install dependencies:
```bash
npm install
```

2. Open `index.html` in your browser or deploy to Vercel

## Deployment

This project is configured for easy deployment on Vercel:

```bash
vercel deploy
```

The Speed Insights will automatically start tracking once deployed to Vercel.

## Speed Insights

This project includes Vercel Speed Insights to monitor real-world performance metrics. Once deployed, you can view metrics in your Vercel dashboard under the Speed Insights section.
